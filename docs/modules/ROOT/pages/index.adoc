= Aragon VE Governance

VE Governance provides token escrow, position NFTs, delegated voting power, gauge voting, and queued withdrawals for Aragon OSx DAOs.

== User and developer guides

The guides and component references live in link:https://github.com/aragon/protocol-doc/blob/main/plugins/ve-governance.md[protocol-doc]. Start with the link:https://github.com/aragon/protocol-doc/blob/main/guides/use-ve-governance.md[VE integration walkthrough] for deposits, delegation, voting, result accounting, and withdrawals.
